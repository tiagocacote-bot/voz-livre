# Privacy / Privacidade

Voz Livre has no login, analytics, advertising SDK or remote backend. Its Android manifest does not request Internet, microphone, camera or broad storage access. Data is stored in the app's private directory; Android cloud backup is disabled. The system photo picker grants access only to selected files. Images are resized before storage.

Speech uses your selected Android TTS engine, which may have its own network behavior and privacy policy. Choose a downloaded offline voice when required. Sharing a message or exporting a backup transfers data to the destination you select. Backups include personal photos and communication data and are not encrypted by the app. The editing PIN prevents accidental changes; it is not encryption or a security boundary. Uninstalling the application may remove local data.

Report code vulnerabilities privately through GitHub's private vulnerability reporting feature if enabled. Otherwise open an issue describing the general problem without private data or an exploit containing personal files. Never attach real family backups, personal photos, passwords or medical records to public issues.

---

Sem login, telemetria, anúncios ou servidor. O manifesto não pede Internet, microfone, câmera ou acesso amplo ao armazenamento. Os dados ficam no diretório privado do app e o backup automático do Android está desativado. O seletor de fotos concede acesso aos arquivos escolhidos; as imagens são reduzidas antes de salvar.

O motor de voz do Android possui políticas e comportamento de rede próprios. Escolha uma voz baixada para uso offline. Exportar ou compartilhar envia os dados ao destino escolhido. Backups contêm fotos e comunicação pessoal e não são criptografados pelo aplicativo. O PIN de edição evita alterações acidentais; não é uma proteção criptográfica. Desinstalar pode apagar os dados locais.

Não publique backups reais, fotos pessoais, senhas ou registros médicos nas issues.
